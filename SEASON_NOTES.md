# Season notes — Sky Runners Club landing page

## Текущий статус (на 27 сентября 2026)

Сезон закрыт на зиму. Открытие — в марте 2027. Telegram-бот (`@skyrunnersclub_bot`)
уже сам показывает сообщение о закрытом сезоне с кнопками (🔔 напомнить об открытии,
💭 оставить пожелание, 💬 наш чат) — это не требует изменений в лендинге.

Лендинг (`index.html` в корне репозитория) на момент закрытия сезона зафиксирован
как есть — полнофункциональная версия с регистрацией, галереей, SEO-разметкой и
фичей выбора дистанции ("Хочу бежать больше 5 км").

## Как восстановить лендинг в марте

1. Убедиться, что репозиторий не менялся с закрытия сезона неожиданным образом
   (`git log --oneline -5` на `main`).
2. Восстановить живую версию из тега:
   ```
   git checkout season-2026-live -- index.html
   ```
   Либо, если тег почему-то потерян, взять копию из архива:
   ```
   cp archive/season-2026-live/index.html index.html
   ```
3. Проверить, что deep-link кнопки в `index.html` (`?start=go`, `?start=long`)
   всё ещё соответствуют тому, что ожидает бот — бот мог измениться за зиму
   (уточнить в сессии, которая работает с ботом/Railway/Timeweb).
4. Закоммитить и запушить через обычный воркфлоу репозитория:
   ветка `claude/busy-pasteur-botov3` → merge в `main` → GitHub Pages
   пересоберёт сайт автоматически.

## Off-season правки (сделаны отдельно, не в этом снапшоте)

Ожидается отдельный проход, который заменит на время закрытого сезона:
- Главную кнопку "Записаться в Telegram →" на "🔔 Напомнить об открытии"
  (ссылка остаётся `?start=go` — бот сам определяет закрытый сезон и
  показывает нужное сообщение, отдельный deep-link параметр не нужен).
- Добавит короткий баннер о том, что сезон закрыт до марта.
- НЕ трогает SEO-метаданные, JSON-LD, галерею, блок "Дистанция" — это
  актуальные факты о клубе, не зависящие от сезона.

## Где что лежит

- `index.html` — текущая (на данный момент — живая) версия лендинга.
- `archive/season-2026-live/index.html` — замороженная копия живой версии
  сезона 2026, идентична коммиту с тегом `season-2026-live`.
- Тег `season-2026-live` на `main` — самая надёжная точка восстановления
  (теги не страдают от случайных force-push/перезаписи веток, в отличие
  от того, что уже один раз случилось с папкой `skyrunners/`).
